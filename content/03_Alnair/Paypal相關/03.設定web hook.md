

1、設定webhook

登錄 https://developer.paypal.com/ 進行 webhook 設定，在用戶自主解除訂閲時能夠收到通知

![[Pasted image 20260222020821.png]]

點擊 App & Credentials -> Alnair，拉到最下方，點擊 Add Webhook

![[Pasted image 20260222020828.png]]

URL 輸入 [https://admin.alnairheyi.com/api/Paypal/returnUrl](https://admin.alnairheyi.com/api/Paypal/returnUrl)

並勾選 All Event

![[Pasted image 20260222020834.png]]

添加后確認清單裏面更新

![[Pasted image 20260222020844.png]]


2、開啓 transaction search 功能

爲了能在後臺能查詢 Subscription 的交易記錄内容，需要在 Paypal 後臺開啓權限，如果有隱私疑慮就不開。

進入 APP 頁面點擊對應APP

![[Pasted image 20260222020849.png]]

下拉到 Feature 區塊勾選 Transaction search

![[Pasted image 20260222020853.png]]

最後點擊 Save 即可

![[Pasted image 20260222020857.png]]
