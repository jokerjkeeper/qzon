

一、登入後台

登入paypald開發者網站 [https://developer.paypal.com/dashboard/](https://developer.paypal.com/dashboard/)

使用自 paypal 帳號登入

![[Pasted image 20260222020434.png]]

登入後可以看到 上面有個 Apps & Credentials 這邊可以申請 apikey, 這是給程式使用的, 右上方有 sandbox / live 切換, 等測試沒問題後可以將 radio 切換成 live, 在 sandbox 模式下只能用 sandbox 的測試帳號


二、申請apikey

![[Pasted image 20260222020439.png]]

點擊 Create App 可以申請新的 Apikey, 在下方已經有一組預設的 apikey 可以使用

點 Create App 新增,

![[Pasted image 20260222020443.png]]

輸入對應的 App Name, 選擇 Merchant(商戶), Create App, 可看到生成出來的 ClientID、Secret Key, 這個需要複製給程式使用

![[Pasted image 20260222020528.png]]

三、申請sandbox測試帳號

點 Testing Tools / Sandbox Accounts 申請測試帳號

![[Pasted image 20260222020505.png]]

可以看到已經有兩組帳號可以使用, 一組是 Personal, 一組是 Business, 測試只要用 personal 這組就可以

![[Pasted image 20260222020537.png]]

點帳號進入可以查閱email、密碼, 點右邊的眼睛顯示密碼


切換成正式環境

1. 在 developer 頁面中切換到 live 模式

![[Pasted image 20260222020543.png]]

2. 切換到 Apps & Credentials 申請 live App

![[Pasted image 20260222020547.png]]

3. 將設定填寫到後台

![[Pasted image 20260222020551.png]]
