

**一、啟動遊戲服務**

新增 {Project}/Config/StartConfig/release.txt 用於服務器啟動配置

![[Pasted image 20260222013522.png]]

InnerConfig 的 Address 配置為內部 ip 0.0.0.0

OuterConfig 的 Address 配置為服務器的外部 ip, 如 58.208.31.224

`$ cd /home/bbom/`

`$ ./Run.sh`


二、啟動外部 mongodb

`$ /usr/local/mongodb/bin/mongod --bind_ip localhost -f /usr/local/mongodb/bin/mongodb.conf`

三、更新外部檔案服務器

`$ cd /usr/share/nginx/html/bbm/`

`$ svn up`

四、更新服務器執行檔

```
$ cd {project}/Server/
$ dotnet publish
```

上傳 {project}/source/Bin 目錄

服務端更新

```
$ cd /home/bbm/
$ svn up Bin
```
