**服務端所有時間都是以 UTC 為基準去做計算**, 客戶端也是以 UTC 為主, 其他需要顯示本地時間的再額外去計算，必須做到服務端跟客戶端的統一校時, 因為服務端跟客戶端的 FrameId 是用為了避免卡頓造成的不準確改用真實時間去計算。

Copy

```
//Utility.cs
private static DateTime bsUtc = new DateTime(1970, 1, 1);
public static long GetUtcTimeStampMinSec() {
    return Convert.ToInt64(DateTime.UtcNow.Subtract(Utility.bsUtc).TotalMilliseconds);
}

//BomberScenarioRoomSystem.cs
long nowts = Utility.GetUtcTimeStampMinSec();
bomberScenarioRoom.StartTime = nowts + (3 * 1000);
bomberScenarioRoom.EndTime = nowts + (3 + desStage.TimeLimit) * 1000;
```
